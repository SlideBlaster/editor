# Math rendering (math.ts)

Fills the engine's `renderMath` seam ([render/html.md](../../editor/src/render/html.md))
with KaTeX, so `$…$` and `$$…$$` typeset on every surface instead of rendering as their
source.

- **Composed into one shared `renderOptions`.** `renderMath` is folded together with the
  table seam into a single `RenderOptions` object ([tableCompiler.md](./tableCompiler.md))
  that is passed to every render call — `paintCanvas` ([canvas.ts](./canvas.md)), the DOM
  measurer ([domMeasurer.ts](./domMeasurer.md)), the navigator thumbnails
  ([deckNav.ts](./deckNav.md)), and the export ([export.ts](./export.md)). Because the
  measurer and the canvas render math identically, measured boxes match what you see.
- **Self-contained styles.** KaTeX needs its stylesheet; `katexInlineCss.ts` is that CSS
  with the woff2 fonts embedded as data URIs (generated by `scripts/genKatexCss.mjs`),
  injected once into the document head by [main.ts](./main.md) and inlined into the export
  document — no CDN, no external font files, offline and CSP-safe.
- **Never throws.** `throwOnError: false` renders malformed math in place (KaTeX's red
  error text) rather than breaking the whole slide render — matching the engine's tolerant
  posture. (Out-of-subset _constructs_ are still the engine's hard error; this is only for
  math syntax inside an accepted `$…$`.)

Regenerate the CSS after upgrading katex: `node scripts/genKatexCss.mjs`.
