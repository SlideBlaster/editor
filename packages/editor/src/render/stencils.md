# stencil registry (stencils.ts)

The geometry backing for imported draw.io stencils. A stencil shape is a `\node` carrying a
`stencil=<id>` option token (see [options.md](../tikz/options.md) `stencilId`); this module maps
that id to a drawable path. Companion design: `design/format/stencil-pipeline.md`.

- **`stencilPath(id)`** — the normalized SVG path `d` for a stencil id, or `undefined` if the id
  is unknown. Data comes from `stencils.generated.ts` (the `STENCILS` registry, GENERATED by
  `packages/editor/tools/stencil-assemble.mjs` — never hand-edited).
- **Normalized coordinates.** A registry `d` lives in a `[0,1]x[0,1]` y-down box, emitting only
  absolute `M`/`L`/`C`/`Q`/`A`/`Z` commands.
- **`placeStencilPath(d, rect)`** — place a normalized path into `rect`, in absolute SVG user
  units. The box scale is **baked into the coordinates**, not applied as an SVG `transform`, so
  the stroke stays a slide-unit width like every other shape (a `scale()` transform would distort
  it; `non-scaling-stroke` would desync it from neighbours at zoom). Coordinate pairs map by
  `x -> rect.x + x*rect.width`, `y -> rect.y + y*rect.height`; an arc's `rx ry` scale per axis and
  its `rotation large sweep` flags pass through; unknown tokens (e.g. `Z`) pass through verbatim.
- **Consumed by** [shape.md](./shape.md): `shapeGeometrySvg`'s `'stencil'` branch emits one
  absolute `<path>` from `placeStencilPath(stencilPath(id), rect)`. So the shapes-panel thumbnail
  and the canvas outline are drawn from the same data and cannot diverge.
