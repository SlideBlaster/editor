# Research

This directory contains time-bounded spikes, measurements, and external
technology findings. Research is evidence, not a decision.

Each research note states:

- question;
- date and tool versions;
- method;
- observations;
- uncertainty;
- recommendation;
- related ADR or vertical slice.

Accepted outcomes are written into architecture, specifications, ADRs, tests,
and the shared knowledge graph. Do not treat an old spike as current authority.
