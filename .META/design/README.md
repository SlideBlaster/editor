# Product design authority

`.META/design/` is the repository-local authority for SlideBlaster product,
format, UX, service, and cross-cutting design. New accepted design belongs here.
Implementation architecture and implementation-only ADRs remain under `docs/`.

The existing `../design/` tree has not yet been migrated. Until a dedicated,
product-owner-reviewed migration session inventories and transfers it, agents
must search both locations and must not delete, rewrite, or treat the legacy
material as superseded merely because this destination exists.

The migration session must preserve provenance, update links, leave migration
notices at legacy entry points, validate local links and indexed knowledge, and
request separate approval before deleting any old copy.
