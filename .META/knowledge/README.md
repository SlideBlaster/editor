# Semantic knowledge authority

`.META/knowledge/` is the repository-local authority for concise durable
SlideBlaster semantic memory. Search it before design or implementation and
update it after an accepted concept changes. Evidence and temporary findings
remain in `.META/research/` until accepted.

The existing `../knowledge/` tree and its current knowledge-base index have not
yet been migrated. Until a dedicated, product-owner-reviewed migration session
inventories, transfers, and reindexes them, agents must search both locations
and preserve the legacy files unchanged.

Migration must validate source coverage, links, index contents, and retrieval
before any separately approved cleanup removes old copies.
